# Triage labels

Map canonical skill roles to these GitHub label names.

| Canonical role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer evaluation required |
| `needs-info` | `needs-info` | More information required from the reporter |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for unattended agent work |
| `ready-for-human` | `ready-for-human` | Human implementation required |
| `wontfix` | `wontfix` | Work will not be undertaken |

When a skill refers to a triage role, use its mapped GitHub label.
Edit the GitHub-label column to change the repository's vocabulary.
